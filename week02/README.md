### 진행 내용

- NumPy: NumPy로 배열과 N차원 배열을 생성하고 연산하며, 리스트보다 편리하고 빠르게 데이터를 처리하는 장점을 이해했다.
- Matplotlib: Matplotlib을 활용해 sin·cos 그래프를 그리고 이미지를 불러오는 방법을 익혔다.
- 퍼셉트론: 퍼셉트론의 구조와 입력, 출력, 가중치, 임계값, 노드 등의 구성요소를 이해했다.
- 논리 게이트: 가중치와 임계값을 조절하여 AND, OR, NAND 게이트를 구현하고 퍼셉트론의 동작 원리를 이해했다.
- 다층 퍼셉트론: 단일 퍼셉트론의 XOR 구현 한계를 이해하고, 여러 퍼셉트론을 연결한 다층 퍼셉트론으로 XOR을 구현하는 방법을 익혔다.
